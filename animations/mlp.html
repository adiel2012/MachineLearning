Multilayer Perceptron Gradient Calculation

This page provides a detailed explanation of gradient calculation in a multilayer perceptron (MLP) for regression tasks, along with an interactive demonstration of training an MLP.

Formulas

Loss Function:

Loss = (1/2) * Σ(y_i - ŷ_i)^2

Output Layer Gradients:

∂L/∂W[2] = (ŷ - y) * A[1]
∂L/∂b[2] = (ŷ - y)

Hidden Layer Gradients:

∂L/∂W[1] = [(ŷ - y) * W[2] * f'(Z[1])] * X
∂L/∂b[1] = (ŷ - y) * W[2] * f'(Z[1])
